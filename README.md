# 🌌 ASTROVIEW

### Explore Beyond What You See

**ASTROVIEW** is an interactive 3D astronomy experience that lets users explore our solar system through an immersive, cinematic web interface.

Instead of presenting planets as static information, ASTROVIEW combines **3D visualization, interaction, animations, and educational content** to create a more engaging way to understand our cosmic neighborhood.

## ✨ Features

- 🌍 Interactive 3D Solar System
- 🪐 Explore planets individually
- 🔍 Planet search and filtering
- 📊 Compare planetary information
- 🎥 Smooth camera movement and animations
- 🚀 Guided exploration experience
- 🌌 Cinematic astronomy-themed UI
- 📱 Responsive interface
- 🛰️ Scroll-based planetary storytelling
- ⚡ Real-time 3D rendering in the browser

## 🛠️ Technologies Used

- **HTML5** — Structure
- **CSS3** — Styling, animations and responsive design
- **JavaScript** — Application logic and interactions
- **Three.js** — 3D rendering and solar-system visualization

## 🧠 How It Works

ASTROVIEW follows a data-driven architecture.

Planet information is stored as structured data, while reusable JavaScript and Three.js logic generates the corresponding 3D objects, orbits, labels and interactions.

### Architecture

```text
Planet Data
     ↓
Three.js 3D Generation
     ↓
User Interaction
     ↓
Centralized Selection
     ↓
UI / Information Display
```

This allows the application to reuse the same rendering and interaction logic across different planets instead of creating separate code for each one.
